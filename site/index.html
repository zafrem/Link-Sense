Browser history, put to work

Bookmark what you actually use.

Link Sense reads your Chrome or Firefox history, ranks every page by how often and how recently you visit it, and lets you turn the winners into tidy bookmark folders. Everything happens on your machine.

How it works

  1. Analyze

    Reads your local history, copies the database first so the original is never touched, and scores every URL.

  2. Review

    Browse the ranked list, search it, pick a folder for each page, and mark what to add or remove.

  3. Apply

    One click writes your choices to Link Sense's store and to real Chrome bookmarks.

Use it as a Chrome extension (recommended) or as a CLI that writes an HTML report and an apply.sh script.

    Scoring

    Each page gets one number:

    score = visit_count × e^(−0.1 × days_since_last_visit)

    Pages you visit often and recently rank highest, and old pages fade on their own. Drag the slider to see a page with 10 visits decay.

    Install

    Chrome extension, Linux with Chrome or Chromium (native installs; Snap and Flatpak builds are not supported).

    1. Install the package from the repository root:

      pip install -e .

    2. Register the native-messaging host:

      link-sense install-host

    3. Open the extensions page, switch on Developer mode, choose Load unpacked and select the extension/ folder:

      chrome://extensions

    4. Click the Link Sense toolbar icon, pick pages, and press Apply. Bookmarks appear under Other bookmarks → Link Sense.

    Prefer the command line? link-sense analyze writes an interactive HTML report. See the README for details.

    Privacy

    Your history stays on your computer. Link Sense copies the browser's history database to a temporary file before reading it, never modifies the original, and sends nothing over the network. This site has no analytics, cookies or third-party scripts.
